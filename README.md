# 🔐 Caesar Cipher

A Python encryption program based on the **Caesar Cipher**, one of the
oldest encryption techniques in history, used by Julius Caesar to
protect military messages.

## ⚙️ How it works
Each letter in the phrase is shifted **3 positions** forward in the alphabet.
Example: `abc` → `def`

## 🖥️ How to use
1. Run the `C.O.D.py` file
2. Choose an option from the menu:
   - `1` Encrypt a phrase
   - `2` Decrypt a phrase
   - `3` Exit
3. Type the desired phrase

## 🛠️ Technologies
- Python 3

## 📌 Note
The program only decrypts phrases that were encrypted
using the same algorithm (3-position shift).
